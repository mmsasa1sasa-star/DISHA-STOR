# 🛍️ DISHA STOR – Handmade Store Frontend

واجهة متجر إلكتروني **مُخصصة للمشغولات والحِرَف اليدوية**،  
موجّهة لأصحاب المشاريع الصغيرة اللي محتاجين حل سريع، بسيط،  
وسهل التخصيص لعرض منتجاتهم أونلاين بدون تعقيد تقني.

🔗 **Live Demo:**  
https://mmsasa1sasa-star.github.io/DISHA-STOR/

---

## 🎯 فكرة المشروع

DISHA STOR **مش متجر عام**،  
هو قالب متجر (Frontend-heavy) موجه لـ:

- 🧶 أصحاب المشغولات اليدوية
- 🎁 الهدايا المصنوعة يدويًا
- 🖐️ الحِرَف المنزلية
- 🚀 المشاريع الصغيرة اللي عايزة حضور أونلاين سريع

الفكرة الأساسية:
> *واجهة جاهزة + إدارة بسيطة + أقل تعقيد ممكن*

---

## ✨ المميزات الرئيسية

- 🎨 تصميم عصري (Modern UI)
- 🌗 **Dark / Light Mode**
- 📱 Responsive بالكامل
- 🛒 سلة مشتريات تفاعلية
- ❤️ نظام مفضلة (Favorites)
- 🔍 بحث وفلترة حسب الفئات
- 🎞️ Animations و Micro-interactions
- ⏳ Preloader مخصص
- 📄 صفحة **404 مخصصة**
- 📣 **Landing Page ترويجية** في البداية
- 🛠️ **Admin Page** لإدارة المنتجات والمحتوى

---

## 🧩 بنية الصفحات

- `index.html` → صفحة الهبوط الترويجية (Landing Page)
- `home.html` → صفحة عرض المنتجات
- `admin.html` → لوحة تحكم بسيطة لإدارة المتجر
- `404.html` → صفحة خطأ مخصصة

---

## 🗃️ قاعدة البيانات (حاليًا)

المشروع يستخدم حاليًا:
- **JSONBin.io** كقاعدة بيانات خفيفة جدًا

الاستخدام:
- تخزين بيانات المنتجات
- Mock API
- سرعة في التطوير والعرض

> ⚠️ **ملاحظة:**  
> JSONBin مستخدم كحل بسيط وسريع،  
> والمشروع جاهز لاحقًا للربط مع:
> - Supabase  
> - Firebase  
> - أو أي Backend API حقيقي

## 🚀 طريقة التشغيل محليًا

1. نزّل المشروع أو اعمل Clone
2. افتح `index.html` أو `home.html`
3. لا يحتاج أي إعدادات أو سيرفر
